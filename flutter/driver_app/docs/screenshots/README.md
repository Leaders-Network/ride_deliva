## 🖼️ Image Specifications

- **Format**: PNG (preferred) or JPG
- **Dimensions**: Mobile screenshots (typical: 1080x2400 or similar)
- **Quality**: High resolution for clarity
- **Background**: Keep as-is from actual app screenshots

## 📝 How to Add Screenshots

1. Take screenshots from your running app (or use existing ones)
2. Rename them according to the list above
3. Place them in this `docs/screenshots/` folder
4. The README.md will automatically display them
